Fleiss' Kappa

How kappa is computed (per label, binary)
For each item, count how many raters said "yes". Compute observed pairwise agreement P̄, then subtract the agreement expected by chance Pe:
κ = (P̄ − Pe) / (1 − Pe)

Example: background (κ = 0.073)
Out of 284 items:
 · 225 items: all 3 agree yes
 · 1 item: all 3 agree no
 · 58 items (20%): genuine disagreement

Observed agreement = 86.4%
Chance baseline = 92x92 + 8x8 = 85.3%
Gap = only 1.1 pp, so kappa = 1.1 / 14.7 = 0.073

The low kappa reflects two things: real disagreement on 58 items, and a chance baseline so high (85.3%) that even genuine agreement barely registers. That is why background is excluded from the macro score.
