Experimental Results — MOKA MultiCite Citation Intent Analysis

Dynamic citation context extraction × multi-label classification · Results for paper discussion
RQ1

Effect of Extraction Strategy on Multi-Label Classification

Dynamic context extraction largely preserves the multi-label classification signal of the full-paragraph baseline, with LLM-based classifiers showing greater robustness to context compression than the supervised classifier.

Preservation Rate (Axis 2)

LLM classifiers retain over 87% of their baseline predictions across all extraction families, reaching 92.2% under LLM-based extraction. MultiCite preservation is consistently lower (69.7–79.7%), indicating that LLM classifiers are considerably more robust to context compression.

Human Agreement Gains (Axis 3)

Dynamic context extraction produces small but generally positive changes relative to the baseline. SciNCL and SPECTER improve Jaccard similarity for 88.9% of models under few-shot prompting, whereas LLM-based extraction improves only 44.4% of models. Given the relatively small evaluation set (n = 284), these gains should be interpreted as directional trends.

RQ2

Supervised versus LLM-Based Classification

LLM-based classifiers consistently outperform the supervised MultiCite classifier across all evaluation axes and extraction configurations. Eight of nine LLM classifiers exceed MultiCite on human Jaccard even on the full-paragraph baseline.

Baseline Performance (Axis 3 — Jaccard)

All nine instruction-based LLM classifiers achieve higher Jaccard agreement scores than MultiCite, with Gemma3-12b obtaining the highest (76.2%). MultiCite achieves 48.3%, the lowest among all classifiers evaluated.

RQ3

Optimal Extraction and Classifier Combinations

Selecting the optimal extraction–classifier combination depends on which evaluation axis is prioritised. No single configuration is optimal across all evaluation axes simultaneously.

The results reveal a trade-off between intent recovery and citation intent preservation. Configurations that maximize expert annotation agreement do not necessarily maximize containment or preservation.

Key trade-off: Gemma3-12b with SciNCL Exp1 achieves the highest agreement with expert annotations (76.7% Jaccard). Gemma2-9b with SciNCL Exp5a achieves near-perfect preservation (100%). These objectives pull in different directions — no single extraction–classifier pair dominates all axes.
Summary RQ3: The choice of extraction–classifier combination should be guided by the deployment objective. If the goal is fidelity to expert annotation (e.g., for digital library enrichment), Gemma3-12b + SciNCL Exp1 is the strongest configuration (76.7% Jaccard). If the goal is prediction stability under context compression, Gemma2-9b + SciNCL Exp5a achieves near-perfect preservation (100%).
